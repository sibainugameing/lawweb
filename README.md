# LawWeb

LawGitのHTTP Integration APIを利用する、Python + Flask製の読み取り専用Webアプリです。

## 画面構成

画面は閲覧の流れに合わせて、概要・法令・ルール・変更履歴・検証の順に移動できる構成です。

- 概要：文書数、最近の変更、よく使う画面への入口
- 法令・ルール：一覧、キーワード絞り込み、種別フィルター、ページ送り
- 詳細：本文と識別情報を分けて表示
- 変更履歴：対象文書のGit履歴から過去の版を開く
- 検証・Git：検証結果とワークツリーの状態を確認

PCではサイドバーと上部検索を使用し、スマートフォンでは下部ナビゲーションと展開式検索を使用します。外部フォント・CDN・解析サービスは使用しません。画面は読み取り専用で、文書の作成・編集・削除を行う操作はありません。

## 法令XMLのMarkdown表示と改正差分

法令詳細では、LawGit XMLを読みやすいMarkdownへ変換して表示します。法令ファイルは変更せず、表示用の変換だけを行います。

- 法令名・法令番号・種別・e-Gov IDをMarkdownの冒頭に表示
- 本則・附則、編・章・節、条を見出しに変換
- 項・号・細目を番号付きリストや入れ子リストに変換
- e-Govの未知の要素もタグ名・属性を付けて表示し、本文を黙って捨てない
- 目次・列記・入れ子の号をリストとして表示
- 別表などの表構造をMarkdownテーブルへ変換し、セル結合属性は注記として保持
- ルビは本文（読み）、上付き・下付きは記号付きで表示
- 条・項・号の削除指定、非表示指定、旧形式・旧番号を注記
- 本則の抄録、附則の制定／改正区分・改正法令番号を注記
- 「整形表示」と「XML原文」を切り替え可能
- ルール本文も保存済みMarkdownとして整形表示

法令の「改正履歴」画面では、比較元と比較先のGitコミットを選択して差分を表示できます。差分は各版のXMLを同じMarkdown変換器に通してから計算するため、XMLのインデントや属性順などの機械的な違いより、条文構造・本文の変更を追いやすくなります。表示はunified diff形式で、追加行と削除行を色分けします。

変換は標準ライブラリのみの `law_markdown.py` で行います。DOCTYPE / ENTITY宣言付きXMLは拒否します。XML原文はAPI応答に保持され、変換できない場合も原文表示へ切り替えられます。法令データ自体のXMLをMarkdownで置き換えたり、Gitに書き込んだりはしません。

## 閲覧範囲

ログインなし：
- 法令名・法令番号・条文本文の全文検索（検索対象は法令のみ）
- 検索結果から法令本文のMarkdown整形表示
- 種別・カテゴリで絞り込んだ法令一覧
- 検索語の候補表示（ブラウザー標準の候補欄）
- 最近の検索語はブラウザータブ内だけで保持し、再読み込み・タブを閉じると消去
- 概要と法令一覧

ログイン後：
- 法令XML全文、識別子、バージョン、ファイル情報
- ユーザールールとMarkdown本文
- 法令・ルールの変更履歴と過去版
- 全文検索
- Gitコミット履歴、変更追従情報、ワークツリー状態、検証結果

LawWebから法令・ルール・Gitリポジトリを書き換える機能はありません。

## 起動

必要なもの：Python 3.10以降、LawGit CLI、curl。

```sh
sh run.sh
```

初回は `.env` が生成されます。次を設定してから再度起動してください。

- `LAWGIT_REPO`：`laws/` と `rules/` を含むデータリポジトリの絶対パス
- `WEB_HOST=0.0.0.0`：同じプライベートLAN内の端末から接続する設定

起動後、このPCでは次を開きます。

```text
http://127.0.0.1:5000
```

同じLAN内のスマートフォン・別PCでは、LawWebを動かしているPCのプライベートIPアドレスを使います。例：

```text
http://192.168.1.20:5000
```

上記のIPアドレスは例です。実際には、LawWebを動かしているPCのWi-Fi／Ethernet側のIPv4アドレスに置き換えてください。mDNSが利用できる環境では、そのPCの `.local` 名も利用できます。

既存の `.env` が旧設定の `WEB_HOST=127.0.0.1` のままなら、Macでは次のコマンドでLAN待受に変更できます。

```sh
sed -i '' 's/^WEB_HOST=.*/WEB_HOST=0.0.0.0/' .env
```

LAN接続を無効にしてこのPCだけで使う場合は、`.env` の `WEB_HOST` を `127.0.0.1` にします。

停止は `Ctrl+C` です。このスクリプトが起動したLawGit APIも一緒に停止します。すでに起動していたAPIは停止しません。

## LANアクセスの範囲と注意

Webサーバーは `0.0.0.0` で待ち受けますが、アプリケーション側で接続元とHostを検査します。

- 接続元：ループバック、IPv4プライベートアドレス（10/8、172.16/12、192.168/16）、IPv6 ULA（fc00::/7）のみ
- Host：ループバック、プライベートIPアドレス、`.local` 名のみ
- 公開IPアドレスからの接続、および公開ホスト名を使った接続は拒否
- X-Forwarded-For等のプロキシヘッダーは信頼しません
- LawGit APIは引き続き `127.0.0.1` でのみ待ち受け、LANに公開しません

この判定は「同じWi-Fiアクセスポイントの端末だけ」を暗号学的に識別するものではありません。プライベートIPアドレスを持つVPNや別の内部ネットワークからも到達できる場合があります。利用するネットワークを信頼できるものに限定し、ルーターのポート転送やインターネットへの公開を設定しないでください。

既定の接続はHTTPです。HTTPではLAN上の第三者による通信の盗聴・改ざんを防げません。信頼できない共有Wi-Fiでの利用や、インターネット越しの利用には適しません。TLSが必要な場合は、証明書検証を行うTLSリバースプロキシを別途設計し、プロキシ境界と接続元検証を見直す必要があります。この構成は未信頼のリバースプロキシをサポートしません。

## アカウント

トップページまたは `/register` から登録できます。登録後は自動的にログインします。

- ユーザー名：3〜32文字。英数字で始まり、英数字・アンダースコア・ピリオド・ハイフンを使用
- パスワード：14文字以上
- 登録試行：接続元ごとに15分間3回まで
- アカウント権限：閲覧専用

ログイン後、画面上部の「アカウント管理」から以下を行えます。

- パスワード変更
- 現在のブラウザー以外のセッション失効
- 現在のパスワードと `DELETE` 入力による自分のアカウント削除

パスワード変更では、既存セッションを失効させて現在のブラウザーに新しいセッションを発行します。自分のアカウント削除では、ほかの利用者のアカウントには影響しません。

## 管理コマンド

パスワード変更：

```sh
.venv/bin/flask --app app change-password --username USERNAME
```

ログイン試行制限の解除：

```sh
.venv/bin/flask --app app reset-login-limits
```

全セッションの失効：

```sh
.venv/bin/flask --app app revoke-sessions
```

特定アカウントの全セッション失効：

```sh
.venv/bin/flask --app app revoke-sessions --username USERNAME
```

全アカウント・全セッション・ログイン試行制限の初期化：

```sh
.venv/bin/flask --app app reset-accounts
```

最後のコマンドは確認入力を要求し、認証データベース内の全ユーザー、パスワードハッシュ、セッション、ログイン試行制限を削除します。`.env`、`instance/secret.key`、法令・ルールデータは削除しません。

アカウント情報は `instance/lawweb.sqlite3`、Flask署名鍵は `instance/secret.key` に保存されます。これらをGitに登録しないでください。

## 設定

| 変数 | 既定値 | 説明 |
|---|---|---|
| `LAWGIT_REPO` | 空 | `laws/` と `rules/` を含むデータリポジトリ |
| `LAWGIT_BIN` | `lawgit` | LawGit CLI |
| `LAWGIT_API_HOST` | `127.0.0.1` | 固定。LawGit APIはループバックのみ |
| `LAWGIT_API_PORT` | `8787` | LawGit APIポート |
| `LAWGIT_TOKEN` | 空 | LawGit APIトークン |
| `LAWGIT_TIMEOUT` | `10` | API接続タイムアウト |
| `WEB_HOST` | `0.0.0.0` | `0.0.0.0` はプライベートLAN対応、`127.0.0.1` はこのPCのみ |
| `WEB_PORT` | `5000` | Web UIポート |
| `LAWWEB_SECRET_KEY` | 空 | 64文字以上の任意署名鍵。空欄なら `instance/secret.key` を生成 |
| `LAWWEB_SESSION_HOURS` | `8` | セッション絶対有効時間（最大24時間） |
| `LAWWEB_IDLE_MINUTES` | `30` | 無操作セッション期限（5〜240分） |

既存の `.env` は `git pull` では書き換わりません。LAN接続を有効にするには、既存の `.env` でも `WEB_HOST=0.0.0.0` に変更してください。

## セキュリティ実装

- パスワードはArgon2idでハッシュ化し、平文では保存しません。
- セッションIDは暗号学的乱数で発行し、DBにはSHA-256ダイジェストのみ保存します。
- セッションは絶対期限と無操作期限を持ちます。
- ログイン・登録・アカウント操作・ログアウトはセッション結合CSRFトークンを検証します。Originが `null` のLANブラウザーでも、有効なトークンが一致し、Fetch Metadataがcross-siteでなく、Refererがある場合は同一オリジンと確認できれば許可します。
- Origin/Referer、Fetch Metadataを検証します。ブラウザーが `Origin: null` を送る場合も無条件には許可せず、トークン一致と `Sec-Fetch-Site: same-origin` を要求します。
- CookieはHttpOnly、SameSite=Laxです。
- CSP、X-Frame-Options、nosniff、Referrer-Policy、Permissions-Policy等を設定します。
- 公開APIは法令メタデータの許可フィールドのみを返します。
- FlaskからLawGit APIへの中継はGETだけです。
- DB・秘密鍵・`.env` はローカルファイル権限で保護します。

## 検証

テストを実行するには、仮想環境内で次を実行します。

```sh
.venv/bin/python -m compileall -q app.py tests
.venv/bin/python -m unittest discover -s tests -v
```

GitHub ActionsでもPython 3.12で構文検査と回帰テストを実行します。

## API連携

ブラウザーは同一オリジンの `/api/*` を呼び、FlaskがLawGit `/api/v1/*` の読み取りAPIだけを中継します。公開APIは `/api/public/*` に分離し、返却フィールドを制限します。LawGitのデータは変更しません。
